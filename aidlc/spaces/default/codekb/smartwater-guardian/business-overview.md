# SmartWater Guardian - ビジネス概要

## プロジェクト目的

消火栓に貼付したIoT音響センサーとハイブリッドAI解析により、水道管の微小漏水を早期検知し、自動資産管理を実現するインフラDX Webアプリケーション。

## ビジネスドメイン

- **対象領域**: 水道インフラ管理（上水道配管管理）
- **顧客**: 自治体・水道局
- **課題**: 配管からの微小漏水の早期検知、資産老朽化管理の自動化
- **ソリューション**: リアルタイムセンサーデータとAI解析による予防的保全

## 主要機能

### 1. 音響テレメトリ取得（BE-1）
- IoT消火栓型センサーから音響データを受信
- Base64 エンコードされた PCM16 モノラル音声
- メタデータ（センサーID、消火栓ID、位置情報、時刻）の検証

### 2. AI信号解析（BE-3）
- FFT（高速フーリエ変換）による周波数スペクトル解析
- 漏水特性帯域のエネルギー検出
- 深刻度判定（Level 0=正常 / 1=微小漏水 / 2=進行性 / 3=破裂）
- 信頼度スコア出力

### 3. 配管台帳参照（BE-4）
- GIS 配管台帳マスタとの連携
- 消火栓ID からの配管属性検索（素材、口径、布設年、埋設深さ）
- 座標からの最近接配管検索（Haversine距離）

### 4. アラート統合API（BE-6）
- テレメトリ一覧・詳細参照
- 配管情報の自動付与
- 深刻度でのフィルタリング
- GeoJSON形式の地図連携出力

### 5. Web UI（FE-3, FE-5）
- React + Leaflet による地図ビジュアライゼーション
- リアルタイムアラート一覧・詳細ドロワー
- センサー位置と漏水エリアの可視化

## ステークホルダー

- **運用者**: 水道局の予防保全・資産管理チーム
- **エンジニア**: 社内DX・IoT開発チーム
- **決裁者**: 自治体の上下水道部門

## 期待値

- 漏水早期検知による破裂・大規模漏洩の防止
- 配管更新計画の最適化（老朽度・漏水リスク考慮）
- 保守作業の効率化（サーベイ → 現場特定の自動化）
- 市民生活への影響低減（断水や道路修復の減少）

## プロジェクト特性

- **Brownfield**: 既存インフラ上での段階的実装
- **MVP重視**: 2026/8/15 デモ完成
- **スケーラビリティ**: 将来の大規模展開を想定した実装
- **セキュリティ**: 出スコープ（認証・権限管理は本プロジェクト外）
