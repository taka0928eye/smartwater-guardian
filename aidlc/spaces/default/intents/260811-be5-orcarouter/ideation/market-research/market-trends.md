# Market Trends — BE-5: Orcarouter による LLM 自動起票

## 市場トレンドの整理（FE-7 成果物の引用）

製品が立脚する市場トレンドは、前段イニシアティブ FE-7 の `ideation/market-research/market-trends.md` に整理済みです。概要は以下のとおりです。 [fe7] [Q3]

- **IoT 音響センサーの常時監視化** — 固定網（Fixed Network）による常時モニタリングが最速の成長セグメント。手動パトロールから常時監視への移行が進む。
- **ビジネスモデル多様化** — Leak Management-as-a-Service（LMaaS）や Technology-as-a-Service（TaaS）のようなサービス型提供が登場。
- **非収益水（NRW）損失の低減** — 漏水による無収水量の削減が導入の主要ドライバー。
- **水道事業体の人員不足** — 高齢化・少子化により自動検針・遠隔監視・AI 分析など自動化技術の導入ニーズが強い。
- **防災・災害耐性への関心** — 洪水管理と連携した早期警報システムの整備が進む。

市場規模の数値（日本のスマート水管理市場、世界の漏水騒音ロガー市場など）も FE-7 成果物に整理済みであり、本イニシアティブでは再調査しません。 [fe7]

## 本イニシアティブに関連するトレンドの示唆

BE-5（LLM 自動起票）に直接関連するトレンドは次の2点です。 [intent]

- **アセットマネジメントの自動化（自動起票）** — 人員不足への対処として、漏水検知の先にある「補修計画・起票」の自動化ニーズが高まります。BE-5 は「検知 → 補修部材選定・概算見積・作業指示書の自動起票」を自動化し、アセットマネジメントの一連の作業を省力化します（intent-statement の問題定義・成功指標と整合）。 [intent]
- **LLM / 生成 AI のインフラ業務への適用** — 生成 AI を業務プロセス（文書起票・見積生成）へ組み込む動きは業界横断で進行しており、水道インフラ分野でも「AI が一次判断・下書きを担い、熟練者・管理者が確認する」運用が現実的になりつつあります。BE-5 は Orcarouter 経由で LLM を呼び、日本語で埋まる部材リスト・見積・手順・通知文面を生成します。 [desc]

## 本イニシアティブへの示唆

- LLM 自動起票は「常時監視（検知）」と「アセットマネジメントの自動化（起票）」の接点に位置し、製品のストーリー（デモ: Level 1 検知 → 判定根拠提示 → 自動起票 → 実測 API 原価）の終盤を担います。 [intent]
- ただし本イニシアティブはデモ評価者向けの機能実装であり、市場開拓・販路設計・トレンドの網羅的追跡は本ワークフローのスコープ外です。 [intent] [Q1]
