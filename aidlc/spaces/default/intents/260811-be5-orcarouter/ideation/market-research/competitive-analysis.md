# Competitive Analysis — BE-5: Orcarouter による LLM 自動起票

## 目的と方法

本分析は、前段のイニシアティブ・ステートメント（`ideation/intent-capture/intent-statement.md`）で確定した BE-5（LLM 自動起票）の市場コンテキストを、製品レベルの競合分析（FE-7 イニシアティブの `ideation/market-research/competitive-analysis.md`）と既存ドキュメント（`docs/business-model.md`・PRD）を引用して整理するものです。新規の外部調査は実施しません。 [Q1] [Q3]

対象は**水道インフラ DX・漏水検知 IoT** 市場です。製品全体の競合分類・主要プレイヤー・ポジショニングは FE-7 成果物に譲り、本分析はその中の **「LLM 自動起票（アセットマネジメント自動化）」機能の差別化の位置づけ**に焦点を当てます。 [fe7] [Q3]

## 競合の分類（FE-7 成果物の引用）

| 分類 | 定義 | 主な対象 |
|---|---|---|
| 直接競合 | 同じ漏水検知・監視課題を IoT 音響センサーで解決 | 富士テコム、HWM、Xylem、Mueller (Echologics)、SebaKMT、Sewerin など |
| 間接競合 | 漏水課題を別方式（スマートメーター・水圧管理・モデリング）で解決 | スマートメーター/AMI ベンダー、水圧管理（PRV）、ネットワークモデリング/デジタルツイン事業者 |
| 潜在競合 | スマート水管理分野で AI 漏水検知へ参入可能な大手・海外勢 | 日立、パナソニック、NEC、富士通などの国内大手と海外ベンダーの日本進出 |

## LLM 自動起票機能の差別化の位置づけ

BE-5 の機能（解析結果と配管台帳から補修部材選定・概算見積・作業指示書を自動起票）は、以下の差別化要素の一角を担います。 [desc]

- **自動アセットマネジメント（検知後の運用自動化）** — 多くの漏水検知ソリューションは「検知（どこで漏れているか）」までで止まり、「補修（どう直すか・いくらかかるか）」の起票は運用スタッフの手作業に残ります。BE-5 は検知後の起票まで自動化し、アラート発生から補修起票までの一連の作業を省力化します（intent-statement の問題定義と整合）。 [intent]
- **実測原価の可視化（FR-6）** — 起票のたびに API 原価・実モデル名・レイテンシを1行 JSON で記録し、画面に「本起票のAPI原価」を表示します（`docs/llm-cost.md` §2.3）。LLM コストを実測で示せる点は、評価軸4における差別化になります。 [intent]
- **フォールバックによる継続性（NFR-5）** — LLM 障害・キー未設定時でも `source == "fallback"` の応答を返し、起票フローを継続させます。LLM 依存の機能にありがちな「LLM 停止＝機能停止」を避けます。 [intent]

## ポジショニング上の注意

- 競合の漏水検知ソリューションが「自動起票」をどこまで提供しているかは、FE-7 の軽量版調査では未詳です（直接競合の網羅性・機能カバレッジは推測に基づく）。デモでは「本プロダクトは検知→起票まで一気通貫で自動化する」点を軸に位置づけ、競合の機能比較までは断定しません。 [fe7] [assumption]

## Assumptions & Open Questions
