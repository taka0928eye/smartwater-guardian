# Stakeholder Map — FE-7 KPIサマリの実データ連携と「試算値」注記

## Key Stakeholders

| ステークホルダー | 関心事 | 役割 | Source |
|---|---|---|---|
| 開発チーム（FE / BE） | KPI を実データで正しく表示し、型の一貫性を保つ。ビルド・テスト・カバレッジ品質の維持 | 実装判断の決定権者 | [Q7] [Q5] |
| PRD / Issue（要件定義） | KPI の実データ連携と「試算値」注記、`SeverityLevel` 型の統一という要件の達成 | 要件の決定者（決定済み） | [desc] [Q1] [Q7] |
| デモ・レビュー評価者（8/15） | 実データ表示と注記表示を目視確認し、デモの完成度を評価 | 最終確認者 | [Q7] [Q5] |
| 水道事業者（オペレータ・管理者） | 監視状況の一覧把握と漏水削減効果（推定削減コスト）の確認 | エンドユーザー | [Q4] |

## Decision-Makers vs. Influencers

- **決定権者**: 開発チームが実装判断を担う。要件は PRD / Issue により決定済み。 [Q7]
- **影響力者**: デモ評価者が最終確認を通じて完了可否に影響を与える。 [Q7]

## Communication Requirements

- 特になし。個別 Issue ベースで進捗管理する（定例レビュー・進捗報告の要件なし）。 [Q8]
