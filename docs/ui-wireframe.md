# UI-1: 画面設計・ワイヤーフレーム定義書

本ドキュメントは、SmartWater Guardian ダッシュボードの画面構成、カラー定義、画面遷移図、および3分間のデモシナリオを確定する設計書である。

---

## 1. 共通カラー定義（深刻度カラー）

画面全体のステータス表示、地図上のマーカー（FE-3）、およびアラート一覧バッジ（FE-5）で共通利用する。

| 深刻度 / 状態 | カラーコード | 意味・対応方針 |
| :--- | :--- | :--- |
| **Level 1** | `#22c55e`（緑） | 微小漏水（経過観察） |
| **Level 2** | `#f59e0b`（黄） | 進行性漏水（要点検） |
| **Level 3** | `#ef4444`（赤） | 管路破裂・大漏水（緊急対応） |
| **正常 (Normal)**| `#64748b`（グレー）| 異常なし |

### 【ドロワー＆モーダル表示】

1. **右スライドイン詳細ドロワー (FE-5 / FE-4)**
   * アラート選択時に右からスライドイン表示。
   * FFT周波数スペクトルグラフ（Recharts: 500〜1500Hzピーク可視化）を表示。
   * 「AI自動起票」ボタンを配置。

2. **中央起票モーダル (FE-6)**
   * 「AI自動起票」押下時に画面中央にポップアップ表示。
   * LLMが自動生成した「適合部材（例: 鋳鉄管150mmクランプ）」「概算見積」「作業指示書」プレビューおよび確定ボタン。

## 3. 画面遷移図 (Mermaid + テキスト代替)

### Mermaid 記法
graph TD
    A[ダッシュボード初期画面] -->|マップ上のピン or アラート一覧クリック| B[右スライドイン詳細ドロワー表示]
    B -->|周波数スペクトルグラフ確認| C[AI自動起票ボタン押下]
    C -->|OrcaRouter呼び出し| D[中央起票モーダル表示]
    D -->|作業指示書確定| E[Teams/Email自動通知 & 完了状態へ更新]

### テキスト代替（画面遷移の補足説明）
1. **初期状態**: 全体マップとKPI、右側のアラート一覧が表示されている。
2. **詳細確認**: マップ上のピンまたは右側のアラートカードをクリックすると、画面右側から「詳細ドロワー」がスライドインし、FFT波形・周波数スペクトルグラフが表示される。
3. **起票実行**: ドロワー内の「AI自動起票」ボタンを押すと、OrcaRouter経由でLLMが駆動し、画面中央に「起票確認モーダル」がポップアップする。
4. **完了通知**: モーダルで指示書を確定すると、Teams/Emailへ通知が飛び、該当ノードのステータスが更新される。

## 4. 3分間デモシナリオ

* **0:00〜0:45 (導入 & 正常時表示)**
  * ダッシュボード画面を提示。KPIサマリ（監視センサー数やコスト削減効果）とGISマップ上の正常ノードを表示し、概要を説明。
* **0:45〜1:30 (漏水検知 & アラート発生)**
  * 疑似データ（Level 1 微小漏水）が発生。GISマップ上の特定の消火栓ピンが赤・黄色に点滅し、右側アラート一覧の最上部に新規通知が追加される。
* **1:30〜2:15 (波形・スペクトル解析表示)**
  * 対象のアラートをクリックし、右スライドイン詳細ドロワーを開く。
  * FFT周波数スペクトル（500〜1500Hz帯のエネルギーピーク）を表示し、AIが人間には不可能な微小漏水を即座に検知した根拠を示す。
* **2:15〜3:00 (AI自動起票 & エージェント連携)**
  * 「AI自動起票」を押下。LLM（OrcaRouter）が管路台帳と照合し、推奨補修部材と概算見積もり、作業指示書を自動生成する様子（中央モーダル）を実演して締めくくる。
